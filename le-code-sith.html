Le Code Sith

La paix n'est que mensonge — « Nwûl tash. » Il n'y a que la passion — « Dzwol shâsotkun. » Par la passion, j'obtiens la puissance — « Shâsotjontû châtsatul nu tyûk. » Par la puissance, j'obtiens le pouvoir — « Tyûkjontû châtsatul nu midwan. » Par le pouvoir, j'obtiens la victoire — « Midwanjontû châtsatul nu asha. » Par la victoire, mes chaînes se brisent — « Ashajontû kotswinot itsu nuyak. » La Force me libérera — « Wonoksh Qyâsik nun. »

Le Code est le fondement même de notre Ordre. À l'origine écrit par Sorzus Sin, puis peaufiné par Marka Ragnos, il constitue la doctrine Sith. Un Sith se doit de suivre le Code Sith à la lettre ; c'est le Code qui dicte ses actes, ses pensées, mais aussi ce qui fait de lui un Sith. Toute personne ne respectant pas le Code ne peut prétendre au rang de Sith.
